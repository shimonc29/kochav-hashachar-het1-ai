# AI EXPO 2026 — כיתה ח׳1

אתר תערוכת עבודות הבינה המלאכותית של כיתה ח׳1, תיכון דעת כוכב השחר.

האתר מבוסס על קובצי HTML/CSS/JavaScript סטטיים. לפרסום באמצעות Vercel יש להעלות את כל תיקיית האתר כך ש־`index.html` יהיה בשורש המאגר, לצד `app.js`, `style.css`, `projects.json`, `projects/`, `assets/` ו־`vercel.json`.

לאחר העלאת קובצי האתר, ב־Vercel בחרו Add New → Project → Import Git Repository, והגדירו Framework Preset: Other, Output Directory: `.`.
