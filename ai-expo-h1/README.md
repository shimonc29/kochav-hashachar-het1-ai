# AI EXPO 2026 — כיתה ח׳1

אתר תערוכת פרויקטים של תלמידי כיתה ח׳1, תיכון דעת, כוכב השחר.

## שימוש

פתחו את `index.html` בדפדפן, או פרסמו את תיקיית הפרויקט ב־Vercel באמצעות GitHub.

## הוספת פרויקט חדש

1. שמרו קובץ HTML תחת `projects/`.
2. הוסיפו אובייקט למערך `PROJECTS` בתוך `app.js` עם `title`, `description`, `category`, `author`, `url`, `icon` ו־`color`.
3. אפשר להוסיף צילום מסך לתיקייה `assets/previews/` ולעדכן `preview`.

## הערות

קובץ המקור של עבודת BarberMatch נשמר כ־`projects/barbermatch.tsx`; גרסת הדפדפן משתמשת ב־React ו־Tailwind דרך CDN ודורשת חיבור לאינטרנט. חלק מעבודות התלמידים האחרות משתמשות גם בשירותים חיצוניים.

שמות התלמידים נלקחו משמות הקבצים; יש לאשר עם בית הספר לפני פרסום ציבורי.
